## 1. האתר → החשבון העסקי

**למה דווקא הוא:** תוכנית Hobby של Vercel חוסמת שימוש מסחרי, **וגם חוסמת פונקציות ב-60 שניות**. `api/staff/voice` מוגדר ל-90. כדאי לבדוק מה התוכנית של החשבון הנוכחי — אם הוא Hobby, ייתכן שדיווח קולי ארוך כבר נחתך בשקט.

| | מה |
|---|---|
| 1 | **GitHub:** להעביר בעלות על `roshinovic2/levi-garage-ai` לחשבון העסקי, ואז מקומית: `git remote set-url origin <הכתובת החדשה>` |
| 2 | **Vercel:** ליצור פרויקט חדש בחשבון העסקי **עם קישור לגיט** (בניגוד להיום, שכל פריסה ידנית) |

⚠️ **מלכודת שכבר הפילה אותנו פעם:** ב-`.env.local` יש הערות באותה שורה של הערך. חילוץ נאיבי גורר את ההערה לתוך הערך ושובר את האתר.

## 3. משתני הסביבה ✅ הוגדרו בשני הצדדים (25.9)

שני הצדדים הוגדרו, והאתר נפרס. **אחרי העברת האתר לחשבון העסקי** מריצים שוב את שני הצדדים עם ה-`SITE_URL` החדש: הסקריפט מוחק ומגדיר מחדש, והטוקן נשמר בקובץ המקומי. ההוראות למטה נשארות לשם כך.

⚠️ **מלכודת שעלתה לנו:** במחשב היה מוגדר `VERCEL_TOKEN` כמשתנה סביבה קבוע של Windows, והוא גבר בשקט על כל `vercel login`. הוא נמחק ב-25.9.

יש סקריפט שעושה את כל זה בפקודה אחת לכל צד, **בלי שאף ערך יודפס או ייכנס לריפו**:

### מה שצריך ממך פעם אחת

**א. חיבור ל-Vercel.** אחת משתי דרכים:

```
$env:NODE_OPTIONS = "--require C:\projects\final-project\levi-garage\scripts\ascii-hostname.cjs"
npx vercel login
Remove-Item Env:NODE_OPTIONS
```

⚠️ **למה השורה הראשונה:** שם המחשב הוא "אלון", וה-CLI של Vercel שולח אותו בכותרת HTTP כשהוא יוצר את טוקן ההתחברות. כותרות HTTP מקבלות רק תווים לטיניים, ולכן `npx vercel login` רגיל נופל עם `is not a legal HTTP header value`. [הקובץ הזה](../../levi-garage/scripts/ascii-hostname.cjs) מחליף את השם ל-`alon-pc` רק בתוך הפקודה הזו, ושם המחשב עצמו לא משתנה. אחרי ההתחברות הוא לא נחוץ: שאר הפקודות לא שולחות את שם המחשב.

או, אם אתה מעדיף שאעבוד בלי שתהיה מחובר: ליצור טוקן ב-Vercel (Settings → Tokens) ולשים אותו **במשתנה סביבה** `VERCEL_TOKEN`, לא בצ'אט.

**ב. קובץ מקומי אחד** בשם `.env.wiring.local`, בתיקייה `03-rollout/solution-3-agent/`. הוא כבר ב-`.gitignore`:

```
SITE_URL=https://levi-garage.vercel.app
NEXT_PUBLIC_WHATSAPP_NUMBER=9725XXXXXXXX
BOT_DIR=C:\projects\Personal-Bot
```

- `SITE_URL` — הכתובת **אחרי** ההעברה לחשבון העסקי, בלי `/` בסוף.
- `NEXT_PUBLIC_WHATSAPP_NUMBER` — המספר שאליו הוואטסאפ באמת מגיע, ספרות בלבד עם קידומת מדינה. **זה המספר האמיתי היחיד בכל המערך**, ולכן הוא חי רק כאן וב-Vercel.
- `GARAGE_BOT_TOKEN` — **לא למלא.** הסקריפט מייצר אותו בהרצה הראשונה, שומר אותו באותו קובץ, ומשתמש באותו ערך בשני הצדדים.

### ההרצה

```
node 03-rollout/solution-3-agent/scripts/wire-garage.mjs site
node 03-rollout/solution-3-agent/scripts/wire-garage.mjs bot
```

| צד | מה מוגדר |
|---|---|
| **האתר** | `GARAGE_BOT_TOKEN` · `NEXT_PUBLIC_WHATSAPP_NUMBER` |
| **הבוט** | `GARAGE_ASK_URL` · `GARAGE_BOT_TOKEN` · `GARAGE_BOOKING_URL` · `GARAGE_PHONE` |

אחרי כל צד צריך פריסה מחדש, כי משתנה סביבה נכנס לתוקף רק בבנייה הבאה. הסקריפט מדפיס את הפקודה המדויקת.

**למה הטוקן בכלל:** בלעדיו, `api/ask` באתר מגביל קצב **לפי כתובת IP**. כל הודעות הוואטסאפ מגיעות מאותו שרת, ולכן לקוח אחד עמוס היה חוסם את כל השאר. עם הטוקן, האתר סופר לכל לקוח בנפרד, לפי HMAC של המספר עם הטוקן כמפתח — כך שהמספר עצמו לא מגיע לאתר.

**`GARAGE_PHONE` הוא המספר הבדוי** `04-0000000`, והוא כתוב בסקריפט בגלוי בכוונה: הבוט מציג אותו ללקוחות, והעסק מדומה.
