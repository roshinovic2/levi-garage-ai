## 1. האתר → החשבון העסקי

**למה דווקא הוא:** תוכנית Hobby של Vercel חוסמת שימוש מסחרי, **וגם חוסמת פונקציות ב-60 שניות**. `api/staff/voice` מוגדר ל-90. כדאי לבדוק מה התוכנית של החשבון הנוכחי — אם הוא Hobby, ייתכן שדיווח קולי ארוך כבר נחתך בשקט.

| | מה |
|---|---|
| 1 | **GitHub:** להעביר בעלות על `roshinovic2/levi-garage-ai` לחשבון העסקי, ואז מקומית: `git remote set-url origin <הכתובת החדשה>` |
| 2 | **Vercel:** ליצור פרויקט חדש בחשבון העסקי **עם קישור לגיט** (בניגוד להיום, שכל פריסה ידנית) |
| 3 | להגדיר שלושה משתנים ב-production: `GEMINI_SA_JSON`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` |
| 4 | לעדכן את הכתובת החדשה ב-`03-rollout/website/README.md` וב-`STATUS.md` |

⚠️ **מלכודת שכבר הפילה אותנו פעם:** ב-`.env.local` יש הערות באותה שורה של הערך. חילוץ נאיבי גורר את ההערה לתוך הערך ושובר את האתר.

## 3. משתני הסביבה ✅ הוגדרו בשני הצדדים (25.9)

שני הצדדים הוגדרו, והאתר נפרס. **אחרי העברת האתר לחשבון העסקי** מריצים שוב את שני הצדדים עם ה-`SITE_URL` החדש: הסקריפט מוחק ומגדיר מחדש, והטוקן נשמר בקובץ המקומי. ההוראות למטה נשארות לשם כך.

⚠️ **מלכודת שעלתה לנו:** במחשב היה מוגדר `VERCEL_TOKEN` כמשתנה סביבה קבוע של Windows, והוא גבר בשקט על כל `vercel login`. הוא נמחק ב-25.9.

יש סקריפט שעושה את כל זה בפקודה אחת לכל צד, **בלי שאף ערך יודפס או ייכנס לריפו**:

### מה שצריך ממך פעם אחת

**א. חיבור ל-Vercel.** אחת משתי דרכים:

```
$env:NODE_OPTIONS = "--require C:\projects\final-project\levi-garage\scripts\ascii-hostname.cjs"
npx vercel login
Remove-Item Env:NODE_OPTIONS
```

⚠️ **למה השורה הראשונה:** שם המחשב הוא "אלון", וה-CLI של Vercel שולח אותו בכותרת HTTP כשהוא יוצר את טוקן ההתחברות. כותרות HTTP מקבלות רק תווים לטיניים, ולכן `npx vercel login` רגיל נופל עם `is not a legal HTTP header value`. [הקובץ הזה](../../levi-garage/scripts/ascii-hostname.cjs) מחליף את השם ל-`alon-pc` רק בתוך הפקודה הזו, ושם המחשב עצמו לא משתנה. אחרי ההתחברות הוא לא נחוץ: שאר הפקודות לא שולחות את שם המחשב.

או, אם אתה מעדיף שאעבוד בלי שתהיה מחובר: ליצור טוקן ב-Vercel (Settings → Tokens) ולשים אותו **במשתנה סביבה** `VERCEL_TOKEN`, לא בצ'אט.

**ב. קובץ מקומי אחד** בשם `.env.wiring.local`, בתיקייה `03-rollout/solution-3-agent/`. הוא כבר ב-`.gitignore`:

```
SITE_URL=https://levi-garage.vercel.app
NEXT_PUBLIC_WHATSAPP_NUMBER=9725XXXXXXXX
BOT_DIR=C:\projects\Personal-Bot
BOT_URL=https://<הכתובת של הבוט>.vercel.app
GARAGE_NOTIFY_ALLOWED=9725XXXXXXXX
```

- `SITE_URL` — הכתובת **אחרי** ההעברה לחשבון העסקי, בלי `/` בסוף.
- `NEXT_PUBLIC_WHATSAPP_NUMBER` — המספר שאליו הוואטסאפ באמת מגיע, ספרות בלבד עם קידומת מדינה. **זה המספר האמיתי היחיד בכל המערך**, ולכן הוא חי רק כאן וב-Vercel.
- `BOT_URL` — הכתובת של הבוט, שאליה האתר פונה כדי לשלוח "הרכב מוכן".
- `GARAGE_NOTIFY_ALLOWED` — מי מותר לקבל "הרכב מוכן". ראו סעיף 5.
- `GARAGE_BOT_TOKEN`, `GARAGE_NOTIFY_TOKEN` — **לא למלא.** הסקריפט מייצר אותם בהרצה הראשונה, שומר אותם באותו קובץ, ומשתמש באותו ערך בשני הצדדים.

### ההרצה

```
node 03-rollout/solution-3-agent/scripts/wire-garage.mjs site
node 03-rollout/solution-3-agent/scripts/wire-garage.mjs bot
```

| צד | מה מוגדר |
|---|---|
| **האתר** | `GARAGE_BOT_TOKEN` · `NEXT_PUBLIC_WHATSAPP_NUMBER` · `GARAGE_NOTIFY_URL` · `GARAGE_NOTIFY_TOKEN` |
| **הבוט** | `GARAGE_ASK_URL` · `GARAGE_BOT_TOKEN` · `GARAGE_BOOKING_URL` · `GARAGE_PHONE` · `GARAGE_NOTIFY_TOKEN` · `GARAGE_NOTIFY_ALLOWED` |

אחרי כל צד צריך פריסה מחדש, כי משתנה סביבה נכנס לתוקף רק בבנייה הבאה. הסקריפט מדפיס את הפקודה המדויקת.

**למה הטוקן בכלל:** בלעדיו, `api/ask` באתר מגביל קצב **לפי כתובת IP**. כל הודעות הוואטסאפ מגיעות מאותו שרת, ולכן לקוח אחד עמוס היה חוסם את כל השאר. עם הטוקן, האתר סופר לכל לקוח בנפרד, לפי HMAC של המספר עם הטוקן כמפתח — כך שהמספר עצמו לא מגיע לאתר.

**`GARAGE_PHONE` הוא המספר הבדוי** `04-0000000`, והוא כתוב בסקריפט בגלוי בכוונה: הבוט מציג אותו ללקוחות, והעסק מדומה.

## 4. מה נבדק, ומה נשאר

| | מה | מצב |
|---|---|---|
| 1 | שאלה במבנה המדויק שהבוט שולח, עם הטוקן, לאתר בייצור | ✅ שעות, מחירים, ותשובה בערבית לשאלה בערבית |
| 2 | מספר הוואטסאפ באתר | ✅ בעברית, בערבית וברוסית |
| 3 | הבעלים והקבוצה לא הושפעו | ✅ בבדיקות האוטומטיות · ⏳ בטלפון אמיתי |
| 4 | **מקצה לקצה, מטלפון שאינו הבעלים** | ✅ שאלה בעברית ושאלה בערבית נענו, כל אחת בשפתה (25.9, 19:00 ו-19:03) · ⏳ תמונה, והבעלים והקבוצה |

### הבדיקה מטלפון אמיתי

זה הדבר היחיד שאי אפשר לבדוק מכאן. **מטלפון שאינו ברשימת הבעלים**, לשלוח לוואטסאפ של המוסך:

| לשלוח | מצופה |
|---|---|
| `מתי אתם פתוחים?` | השעות: א׳–ה׳ 07:00–17:00, ו׳ עד 12:00 |
| `אני רוצה לקבוע תור` | תשובה, ומתחתיה שורה עם הקישור לקביעת תור |
| תמונה כלשהי | "כאן אני קורא רק טקסט" והטלפון |
| `متى تفتحون؟` | אותן שעות, בערבית |

**ומהטלפון שלך**, הודעה רגילה: אמורה להגיע לעוזר האישי כמו תמיד. **ובקבוצה המשותפת**, "בוט ...": כמו תמיד.

**על איזה מספר זה רץ:** מספר נפרד, העסקי של בעל הפרויקט, ולא המספר האישי שלו. כרגע אף אחד אחר לא פונה אליו, ולכן הבוט נשאר דלוק עד אחרי ההדגמה. **ברגע שאנשים אמיתיים יתחילו לכתוב למספר הזה, כל מי שאינו ברשימת הבעלים יקבל תשובה של המוסך, והטקסט שלו יישלח לאתר.** בשלב הזה צריך לכבות את הבוט.

**איך מכבים את התשובות אחרי ההדגמה:** מוחקים את `GARAGE_ASK_URL` מהבוט ב-Vercel ופורסים מחדש. מאותו רגע זרים נדחים בשקט, כמו קודם.

## 5. "הרכב מוכן" (שלב ג') — צעד אחד שלך

הקוד חי בשני הצדדים. באתר המשתנים כבר הוגדרו והוא נפרס. בצד הבוט חסר דבר אחד, ורק אתה יכול לספק אותו: **למי מותר לשלוח.**

**למה צריך רשימה:** המוסך בדוי, ולכן כל טלפון של "לקוח" בנתונים הוא נתון בדיקה. **`0500000001` מנתוני הדמו יכול להיות של אדם אמיתי.** בלי רשימה, לחיצה על "מוכן" בהדגמה הייתה שולחת לו "הרכב שלך מוכן". לכן בבוט רשימה ריקה פירושה אף אחד.

### מה להוסיף

שורה אחת בקובץ `03-rollout/solution-3-agent/.env.wiring.local`:

```
GARAGE_NOTIFY_ALLOWED=9725XXXXXXXX,9725YYYYYYYY
```

ספרות עם קידומת מדינה, מופרדים בפסיק, **רק מי שהסכים לקבל הודעה בהדגמה.** המספר הראשון ישמש לתור ההדגמה. אופציונלי: `DEMO_NAME=...`, השם שיופיע ב"שלום ...".

### ואז (אני יכול להריץ את זה)

```
node 03-rollout/solution-3-agent/scripts/wire-garage.mjs bot      # מגדיר את הטוקן והרשימה בבוט
# פריסה מחדש של הבוט (קומיט ריק, כמו ב-"redeploy after rotating")
cd levi-garage && node --env-file=.env.local scripts/seed-demo-notice.mjs   # תור להדגמה, עם המספר הראשון
```

### ההדגמה

1. להתחבר כדניאל (`test1@test.com`) ← "לוח היום" ← לפתוח כרטיס לסקודה FABIA.
2. בכרטיס: **"הרכב מוכן"**.
3. **✅ מצופה:** בטלפון מגיעה ההודעה, ובכרטיס מופיעה שורה ירוקה "נשלחה ללקוח הודעת וואטסאפ שהרכב מוכן · שעה".
4. לחיצה על "מוכן" בכל רכב אחר מהדמו: **✅ מצופה:** שום הודעה לא יוצאת, ובכרטיס "לא נשלחה הודעה ללקוח: המספר לא ברשימת ההדגמה".

**לכבות רק את "הרכב מוכן":** למחוק את `GARAGE_NOTIFY_TOKEN` מהבוט ב-Vercel ולפרוס מחדש. הכרטיסים ימשיכו לעבוד, ויציגו שההודעה לא יצאה.
