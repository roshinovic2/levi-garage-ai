# מוסך לוי ובניו: פרויקט גמר AI Game Changer (מחזור 6)

> **לבוחני הפרויקט:** הריפו מכיל את כל תוצרי הפרויקט לפי מודל **CORE**: אפיון, תכנון, בנייה ומסירה. המסמך המלא להגשה נמצא ב-Google Docs, והריפו הזה הוא "המנוע" שמאחוריו: הפרומפטים, הקוד, התמלילים, צילומי המסך והבדיקות.
> **שקיפות:** העסק **בדוי**. בנינו לו פרופיל מפורט ואימתנו אותו בשני ראיונות עצמאיים, אחד מהם מול Mr. Client, הסוכן הרשמי של הקורס. פירוט ב-[01-clarify/clarify-final.md](01-clarify/clarify-final.md), סעיף 8.

## העסק בשורה אחת
מוסך משפחתי עצמאי בקריות: 4 ליפטים, כ-15 רכבים ביום, 7 עובדים, צוות שמדבר עברית, ערבית ורוסית.
**כוכב הצפון, בלשון הבעלים:** "תעיף ממני את תפקיד המרכזייה והמתווך... הבעיה שלי היא השעות המתות של הליפטים שמחכים לתשובות של בני אדם."
**עיקרון-על:** **אפס הקלדה.** הנתונים נכנסים דרך מה שכבר קורה היום: הודעה קולית, צילום ומספר רישוי.
